Keamanan baru: token sesi, bukan kunci API statis.

Yang baru
• Aplikasi memakai token sesi yang hanya berlaku 24 jam, bukan kunci statis yang bisa dibaca siapa pun dari file APK.
• Token diperbarui otomatis tanpa perlu buka aplikasi lagi, jadi tidak perlu install ulang.
• Server hanya memberi token ke aplikasi yang bertanda tangan resmi. Aplikasi tiruan atau yang sudah dimodifikasi akan ditolak.
• Penyimpanan token dipindahkan ke penyimpanan aman milik Android (Android Keystore), sehingga tidak bisa dicuri oleh aplikasi lain di HP yang sama.

Tidak ada perubahan tampilan. Tidak perlu logout. Aplikasi memperbarui dirinya sendiri seperti biasa.
